# Django Blog

Simple blog website where you can create , update or delete posts
The project is built using Python Django with a modern design using Bootstrap.

## Features

You have the abillity to:

1. Create an account 
2. Login to your account using username and password
3. View posts by yourself or others ordered by newest first
4. Create, update or delete your own posts.
5. Choose a unique username and update your profile and avatar anytime
6. Each user has a page containing all their posts
7. Forget password sends an email to reset password to your email
